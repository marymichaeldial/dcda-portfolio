Part 2 — Interactive Hometown Map

The map below was generated using Python (Folium) and displays 10 personally meaningful locations in Tyler, Texas. Each marker is color-coded by location type — restaurants in red, parks in green, cultural sites in purple, and so on. Click any marker to see a description and image of the location.

Reflection

Design Inspiration

I chose A Sailor's Guide to Earth by Sturgill Simpson as my design inspiration because the album's artwork captures something rare — a sense of vastness and intimacy at the same time. The deep navy of the ocean, the warm golden horizon, and the weathered, nautical textures all felt like they belonged on a map. I extracted the core colors directly from the cover and applied them systematically: dark water, parchment land, cream roads, and sage green for parks. The result feels cohesive and intentional rather than arbitrary.

Cartographic Challenges

The biggest challenge in Mapbox Studio was designing for multiple zoom levels. At a world scale, only the water and land colors matter — labels and roads are too small to read. As you zoom in, roads and place labels need to appear progressively. I had to think carefully about what should be visible at each level so the map didn't feel cluttered at high zoom or empty at low zoom. Hillshade was also tricky — too much opacity overwhelmed the parchment land color, so I kept it subtle.

Technical Challenges

Setting up the Python environment on a Mac was unexpectedly the hardest part — pip and python commands didn't work because the system uses pip3 and python3. I also had to make sure the CSV and script were in the same folder before running. I used Claude (AI) extensively to generate the Python code, and while I didn't write it from scratch myself, I worked through it line by line to understand what each section does — reading the CSV, calling the Mapbox geocoding API, building the Folium map, and saving the HTML output.
