Lab 6 — Interactive Mapping
with Mapbox & Python

Course DCDA 40833
Tools Mapbox Studio · Python · Folium
Location Tyler, Texas (10 sites)

Lab Requirements

Design a custom basemap style in Mapbox Studio. Build a CSV dataset of at least 10 meaningful locations. Use Python and Folium to generate an interactive HTML map from the data. Embed the map in the portfolio. Write a reflection on design choices and technical challenges.

This was the most technically complex lab of the semester — it combined four distinct tools and required solving real integration problems rather than following a clean step-by-step tutorial.

How I Built It

  1. Mapbox Studio — Custom Basemap

    Designed a new map style inspired by Sturgill Simpson's A Sailor's Guide to Earth. Adjusted water, land, road, and label colors to match the album's nautical palette.

  2. CSV Dataset — 10 Tyler, TX Locations

    Built a spreadsheet with name, latitude, longitude, category, and description for 10 personally meaningful places in Tyler. Saved as hometown_locations.csv.

  3. Python + Folium — Interactive HTML Map

    Ran generate_lab06.py in Terminal using python3. The script reads the CSV with pandas, creates a Folium map centered on Tyler, and adds a color-coded marker with popup for each row.

  4. Embed — iframe in Portfolio

    Embedded the Folium output (hometown_map.html) directly in this page using an <iframe> tag. The iframe displays the fully interactive map inline.

Part 1 — Custom Mapbox Basemap

My basemap design was inspired by the album artwork of Sturgill Simpson's A Sailor's Guide to Earth. The cover features deep navy ocean tones, warm golden horizons, and an aged nautical aesthetic that felt naturally suited to a map.

I translated these visual elements into a color palette centered on dark navy water, aged parchment land, and warm cream roads. The result feels cohesive and intentional rather than arbitrary.

Cartographic Challenges

The biggest challenge was designing for multiple zoom levels. At world scale, only water and land colors matter — labels and roads are too small to read. As you zoom in, roads and place labels need to appear progressively. I had to think carefully about what should be visible at each zoom level so the map didn't feel cluttered zoomed in or empty zoomed out. Hillshade was also tricky — too much opacity overwhelmed the parchment land color, so I kept it very subtle.

Reflection

Design Inspiration

I chose A Sailor's Guide to Earth by Sturgill Simpson as my design inspiration because the album's artwork captures something rare — vastness and intimacy at the same time. The deep navy ocean, warm golden horizon, and weathered nautical textures all felt like they belonged on a map. I extracted the core colors directly from the cover and applied them systematically across water, land, roads, and parks.

Technical Challenges

Setting up the Python environment on a Mac was unexpectedly the hardest part — pip and python commands didn't work because macOS uses pip3 and python3. I also had to make sure the CSV and script were in the same folder before running. I used AI extensively to generate the Python code, but worked through it line by line to understand what each section does — reading the CSV, building the Folium map, and saving the HTML output.

The most important lesson of this lab wasn't about mapping — it was about debugging. Every error had a solution; finding it required reading the error message carefully and testing one change at a time.

What This Demonstrates

Lab 6 is the most technically complex work in this portfolio. It combines four distinct tools and required me to solve real integration problems. The Tyler, TX dataset is personal — these are places that matter to me, and choosing my hometown as the subject of the first real map I ever made felt right.

Building this lab also pushed my HTML skills further than any previous assignment. Embedding a live interactive map into a portfolio page — and making it look like it belongs there — required understanding how CSS, JavaScript, and HTML work together at a level I didn't have before.
